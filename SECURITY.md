# Security policy

Do not report secrets, Temporary Access Pass values, tenant identifiers that are not already public, or emergency-account details in a public issue.

Report vulnerabilities privately through GitHub's security advisory workflow for this repository. Include the affected deployment mode, reproducible behavior, and suggested mitigation when available.

This project intentionally does not persist passwords, TAP values, Function keys, or storage keys. A report that includes any such value should be treated as compromised and rotated before submission.
